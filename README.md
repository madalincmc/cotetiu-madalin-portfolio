# Madalin Cotetiu — Portfolio & Blog

Personal engineering portfolio, technical blog, and interactive résumé, built as a content-driven
Next.js site. See [prd.md](./prd.md) for the product requirements and
[implementation-plan.md](./implementation-plan.md) for the architecture and phased build plan.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · Motion ·
Fumadocs MDX · Zod · Pagefind · `@react-pdf/renderer`

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Note: global search (Ctrl/Cmd+K) only works after a production build — the Pagefind index is
generated by a `postbuild` script, not available under `next dev`.

## Content

All content lives outside `src/` and can be edited without touching application code:

- `content/blog/*.mdx` — blog posts (`draft: true` posts show under `next dev` only). Use the
  `/blog-post` Claude Code skill (`.claude/skills/blog-post/`) to draft a post with its images.
- `content/projects/*.mdx` — portfolio projects
- `content/resume/resume.data.ts` — résumé data (also drives the generated PDF)

## Scripts

| Script                          | Purpose                                                                                                     |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `npm run dev`                   | Start the dev server                                                                                        |
| `npm run build`                 | Production build — also regenerates the résumé PDF (`prebuild`) and the Pagefind search index (`postbuild`) |
| `npm run start`                 | Serve the production build                                                                                  |
| `npm run lint`                  | ESLint                                                                                                      |
| `npm run format`                | Prettier (writes)                                                                                           |
| `npm run generate:resume-pdf`   | Regenerate the résumé PDF on its own                                                                        |
| `npm run generate:search-index` | Rebuild the Pagefind index on its own                                                                       |
| `npm run blog:cover -- <slug>`  | Generate a post's cover PNG from its frontmatter (`--missing` for every post without one)                   |
| `npm run blog:preview-svg`      | Rasterize a diagram SVG to PNG for a visual check (`-- <in.svg> <out.png>`)                                 |
