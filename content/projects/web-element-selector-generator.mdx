A Chrome and Firefox (Manifest V3) extension that turns any element — or an entire page — into ready-to-use CSS, XPath, ARIA, and Playwright locators, plus copy-paste code snippets for Selenium, Playwright, Cypress, and WebdriverIO. Built for test automation, web scraping, and debugging.

## Features

- 8 locator strategies per element: CSS relative/absolute, XPath relative/absolute, CSS attribute-contains, XPath text-contains, ARIA role/name selector, and Playwright locator code, with a "recommended" badge highlighting the most robust option
- **Full-page scan**: a side panel that scans every interactive element on the page in one pass, across same-origin *and* cross-origin iframes, with search/filter, hover-to-highlight, and multi-select
- **Code snippets** for the most common test-automation stacks — Selenium (Java/Python/C#/JS), Playwright (JS-TS/Python/Java/C#), Cypress, and WebdriverIO — per element or as a ready-to-paste Page Object class for a batch of selected elements
- Works inside open shadow roots and same-origin iframes
- "Validate All" checks every generated selector live against the page and reports match counts
- Per-tab selection history, a right-click context menu entry, and an `Alt+Shift+E` keyboard shortcut
- Configurable attribute priority order, default snippet framework/language, and JSON/CSV export of selection history
- Everything runs locally — no data ever leaves the browser

## How it works

The extension is split into six parts: a content script injected into every frame that builds all 8 locator strategies and powers the full-page scan (including cross-origin iframes, since each frame's content script runs independently); a background service worker that relays messages, keeps per-tab history, and orchestrates scans across frames; the popup and side-panel UIs; a shared snippet generator for the supported test frameworks; and a settings page for attribute priority and defaults.

## Use cases

- Writing test automation code without hand-crafting locators in devtools
- Bootstrapping a Page Object Model by scanning a page once and exporting a full class skeleton
- QA sanity-checking a selector's stability before handing it to an automation engineer
- Web scraping — grabbing a unique CSS/XPath path to a data element, or scanning a whole listing page at once
- Accessibility auditing via the ARIA role/name output
- Debugging elements inside shadow DOM or embedded iframes, where devtools' own "copy selector" falls short
